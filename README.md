# 🏨 Hotel Data Web Scraping Project

## 📌 Overview
This project demonstrates web scraping using **Python** to collect hotel information from [OYO Rooms](https://www.oyorooms.com/) listings in Chennai.  
The goal was to extract structured data such as hotel names, addresses, ratings, and prices across multiple pages and convert it into a **pandas DataFrame** for further analysis.

## ⚙️ Tools & Libraries Used
- **Python 3**
- **BeautifulSoup** → for parsing HTML
- **requests** → for sending HTTP requests
- **pandas** → for storing and cleaning data

## 🚀 Features
- Scrapes hotel listings across multiple pages.
- Extracts:
  - Hotel title
  - Address
  - Number of ratings
  - Star rating
  - Price
- Stores results in a structured format (list of dictionaries).
- Converts scraped data into a **pandas DataFrame** for easy analysis
